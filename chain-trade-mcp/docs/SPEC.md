# Chain Trade MCP - 系统规范

## 概述

为 Web3 量化智能体提供 **真实、可执行、可审计** 的链上与市场能力，用于自动化交易与风险控制。

---

## 1. 目标与非目标

### ✅ 目标（Goals）

| 目标     | 描述                           |
| -------- | ------------------------------ |
| 真实性   | 提供可验证的链上与市场数据     |
| 可执行性 | 支持真实的代币交换、转账等操作 |
| 可审计性 | 所有操作可追溯、可验证         |

### ❌ 非目标（Non-Goals）

- ❌ 不负责策略生成或参数优化
- ❌ 不自动扩大权限（所有执行需显式参数）
- ❌ 不隐藏失败或重试逻辑
- ❌ 不做预测、情绪或主观判断

---

## 2. 系统约束（Constraints）

| 约束类型     | 要求                    |
| ------------ | ----------------------- |
| **调用方式** | 同步请求 / JSON 返回    |
| **执行环境** | Rust 后端，单进程可运行 |

### 权限模型

- **查询类工具**：只读权限
- **执行类工具**：需显式授权（私钥 / signer 已配置）

### 失败语义

> ⚠️ **重要**：失败必须返回错误，**不允许 silent failure**

---

## 3. 工具分级

| 级别   | 定义                         | 优先级 |
| ------ | ---------------------------- | ------ |
| **P0** | 必须工具，真实交易不可或缺   | 最高   |
| **P1** | 推荐工具，显著提高胜率与风控 | 中高   |
| **P2** | 可选工具，策略依赖           | 可选   |

---

## 4. 工具详细说明

### 🔴 P0 · 必须工具（真实执行）

> 这些工具是真实交易的核心组件，缺一不可。

| 工具名称          | 功能描述          | 输入要求                             | 输出要求                                   |
| ----------------- | ----------------- | ------------------------------------ | ------------------------------------------ |
| `get_balance`     | 真实查询链上余额  | ETH / ERC20 地址                     | 直接 RPC 或 indexer 返回                   |
| `token_price`     | 真实市场价格查询  | 代币标识                             | 多来源任选其一，返回最近可得价格           |
| `swap_tokens`     | 真实执行 DEX 交易 | dex / router, slippage, 输入输出参数 | 返回真实 `tx_hash`，失败即失败，不自动重试 |

#### swap_tokens 强制要求

```
✅ 必须：明确 dex / router
✅ 必须：明确 slippage
✅ 必须：明确最大输入或最小输出
❌ 失败即失败，不自动重试
```

---

### 🟡 P1 · 推荐工具（真实数据）

> 这些工具提供真实数据支持，显著提升策略效果。

| 工具名称                   | 功能描述              | 数据来源       | 限制                                 |
| -------------------------- | --------------------- | -------------- | ------------------------------------ |
| `news_search`              | 真实新闻源检索        | RSS / 公共 API | 返回原始内容，不做总结、不做打分     |
| `onchain_transfer_monitor` | 真实链上转账记录查询  | 链上数据       | 用于监控异常资金流，不做地址标签推断 |
| `market_volume`            | 真实成交量 / 价格变化 | 真实 DEX / CEX | 用于流动性与波动过滤                 |

---

### 🔵 P2 · 可选工具

| 工具名称       | 功能描述            | 备注                       |
| -------------- | ------------------- | -------------------------- |
| `equity_price` | 真实股票 / 指数价格 | 仅查询，不影响链上执行流程 |

---

## 5. 系统不变式（Invariants）

> ✅ 这些规则在任何情况下都必须成立：

1. **任何执行类工具** 最多产生 **一次** 链上交易
2. 工具不得隐式修改交易参数
3. 同一输入不得导致不确定行为
4. **查询失败 ≠ 执行失败**，二者严格区分

---

## 6. 验收标准（Acceptance Criteria）

### 连续执行测试

| 测试项     | 数量           | 要求       |
| ---------- | -------------- | ---------- |
| 查询类调用 | 1000 次        | 系统不崩溃 |
| 真实 swap  | 100 次（小额） | 系统不崩溃 |

### 每笔交易结果

| 结果   | 要求           |
| ------ | -------------- |
| ✅ 成功 | 返回 `tx_hash` |
| ❌ 失败 | 明确失败原因   |

---

## 7. 执行安全约定（Minimal）

### 后端持有

- 受限私钥或 signer
- 最小权限原则

### Agent 不能执行的操作

| ❌ 禁止操作        | 原因               |
| ----------------- | ------------------ |
| 修改 gas 策略上限 | 防止意外高额手续费 |
| 绕过 slippage     | 防止恶意滑点损失   |
| 发起无限授权      | 防止代币被恶意转移 |

---

## 8. 快速参考

```
工具调用流程：
  1. 查询类 → 直接调用，只读返回
  2. 执行类 → 需授权，参数明确
  3. 结果 → 成功返回 tx_hash，失败返回错误
```

> **核心原则**：透明、可控、可审计
